# THE LOST HORIZON — First Expedition

Browser-based third-person 3D exploration prototype. Open the GitHub Pages deployment on desktop or mobile. Three.js is loaded from jsDelivr, so an internet connection is required.

Controls: WASD/arrows to move, Shift to run, drag to rotate camera, E to activate the altar. On touch devices use the left virtual stick and the E button.

Goal: collect three glowing sigils and return to the central altar.
